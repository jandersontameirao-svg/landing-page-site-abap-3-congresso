# 3º Congresso Anual da ABAP

Landing page oficial do **3º Congresso Anual da Associação Brasileira de Arqueologia Preventiva (ABAP)**.

**Tema:** _"Licenciamento Ambiental & Patrimônio Cultural"_
**Data:** 08 e 09 de outubro de 2026
**Local:** Sala Tom Jobim — Ed. Parlamundi (Templo LBV), Asa Sul — Brasília/DF
**Inscrições:** [Sympla](https://www.sympla.com.br/evento/3-congresso-anual-abap/3574724)

## Estrutura

```
.
├── index.html      # Página única (HTML + CSS + JS inline)
└── assets/         # Imagens (logos, fotos dos locais, patrocinadores)
```

Site estático, sem dependências ou build. Basta abrir o `index.html` no navegador.

## Publicação

Compatível com qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).
Para GitHub Pages: ativar em **Settings → Pages → Deploy from branch → main / root**.
